# BALLTBALL CROSS 🏐

온라인 3D 비치발리볼 — 웹 브라우저에서 친구들과 함께 즐기는 실시간 멀티플레이 배구 게임.

## 특징

- **《The Spike》 스타일 메타게임 셸** — "아무 키나 눌러 시작" 시네마틱 스플래시 → 홈 허브(재화·출석·미션) → 경기 모드 선택. 모든 메뉴 뒤에서 실제 3D 선수들이 랠리 워밍업을 하는 살아있는 배경이 돌아갑니다 (외부 이미지 0장, 전부 3D·절차 생성)
- **실시간 온라인 멀티플레이** — 서버 권위(server-authoritative) 시뮬레이션 60Hz + 클라이언트 예측/보간으로 부드러운 플레이
- **2v2 / 1v1** — 빈 자리는 AI 봇이 자동으로 채워줍니다. 혼자서도 바로 플레이 가능
- **풀 3D 그래픽** — Three.js 기반 해변 코트, 동적 그림자, 파티클 이펙트, 시네마틱 카메라 (외부 에셋 없이 100% 절차 생성)
- **배구 룰** — 서브, 리시브, 토스, 스파이크, 블로킹, 3터치 제한, 랠리 스코어 15점(듀스, 21점 캡)
- **메타 콘텐츠** — 일일 미션(실제 플레이 연동), 상점(볼 스킨·메뉴 테마 실제 적용), 선수 관리(절차 생성 포트레이트), 출석 보상 — 로컬 저장으로 진행 유지
- **절차 합성 사운드** — WebAudio로 만든 타격음, 휘슬, 관중/파도 소리

## 실행

```bash
npm install
npm run dev        # 개발: 서버(3001) + 클라이언트(5173) 동시 실행
```

브라우저에서 **http://localhost:5173** 접속.

프로덕션:

```bash
npm run build      # dist/ 생성
npm start          # 단일 서버가 정적 파일 + 웹소켓 서빙 (PORT 환경변수, 기본 3001)
```

같은 네트워크의 친구와 하려면 방화벽에서 포트를 열고 `http://<내IP>:5173` (dev) 또는 `:3001` (prod)로 접속하면 됩니다.

## 조작법

| 입력 | 동작 |
|---|---|
| `W A S D` / 방향키 | 이동 |
| `Space` | 점프 |
| 마우스 이동 | 조준 (상대 코트의 원하는 지점) |
| 좌클릭 / `J` / `Z` | 공격 · 스파이크 · 서브 |
| 우클릭 / `K` / `X` | 토스 · 리시브 (팀원에게 연결) |
| `ESC` | 메뉴 |

**팁**: 점프 중에 네트 위 높이의 공을 좌클릭하면 강력한 **스파이크**가 나갑니다. 네트 앞에서 점프하면 상대 스파이크를 **블로킹**할 수 있어요.

## 게임 방법

1. 닉네임 입력 → **빠른 대전** (아무나 매칭) 또는 **방 만들기** (코드를 친구에게 공유)
2. 로비에서 팀 선택 후 **준비 완료** — 전원 준비되면 시작, 또는 **봇 채우고 바로 시작**
3. 랠리에서 이기면 득점 + 서브권. **15점 선취 (2점 차, 21점 캡)** 승리

## 기술 구조

```
shared/         물리 엔진 · 게임 룰(GameSim) · 네트워크 프로토콜 — 서버/클라이언트 공유
server/         Node.js + ws — 방/매치메이킹, 권위 시뮬레이션 틱 루프, 봇 AI
client/         예측/보간 넷코드 · 인게임 HUD · WebAudio
client/render/  Three.js 렌더러 + showcase.ts(메뉴용 시네마틱 3D 배경)
client/meta/    《The Spike》 스타일 프론트엔드 — 스플래시·허브·상점·미션·선수관리 (디자인 시스템/스토어 포함)
scripts/        smoke.ts(서버+2클라이언트 E2E) · verify-fixes.ts(물리/룰 회귀)
```

- 서버가 유일한 진실(60Hz 시뮬레이션), 클라이언트로 30Hz 스냅샷 전송
- 내 캐릭터는 **클라이언트 예측 + 서버 재조정**, 상대/공은 **100ms 보간** (+ 공 외삽)
- 입력은 라이징 엣지 래치로 처리(지터 버스트에서도 탭 유실 없음), 서버는 모든 입력을 검증·클램프
- 검증: `npm run typecheck` · E2E: `npm run smoke` · 물리/룰 회귀: `npm run verify`
